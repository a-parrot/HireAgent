# 2026-11-14

## HireAgent 前端开发（完成初版）

- 需求：基于已完成的 FastAPI 后端（岗位/批次/候选人/审核/排期/动作/日志/导出，接口契约见 docs/api/后端接口说明.md 与 openapi.json），在 frontend/ 空目录骨架上完成前端开发。
- 技术栈：Vue 3.5 + TypeScript + Vite 6 + Element Plus 2.9 + Pinia + Vue Router 4，axios。
- 关键后端契约（研究自后端代码，openapi 未定义响应 schema）：
  - 所有响应由 ORM serialize() 生成，`id`/`*_id` 整型列序列化为**字符串**；datetime 为 ISO8601（带 Z 后缀）。
  - 关键端点：POST /batches（multipart: job_id/rule_version_id/files[]/name，返回含 imported_count）；GET /batches/{id} 追加 progress{pending,running,waiting_review,completed,failed}+total；POST /batches/{id}/run 幂等（already_started）；GET /candidates/{id} 含 review_history/reservation/actions；events 用 after_id 游标（next_cursor）；slots 固定 45 分钟、每批 4 个；排期 POST 要求 evaluation_done+4 时段；action-preview GET/PUT/approve/retry/reconcile。
- 页面：岗位管理（草稿编辑 draft_version 乐观锁、发布需 operator_name、版本快照）、批次（创建/上传 PDF、5 状态进度、启动/重试、PDF iframe 预览 #page=N 定位、JSON/CSV 导出、执行中 5 秒轮询）、候选人详情（硬条件/维度评分/证据页码定位/审核表单 supplement+supplements）、排期（时段 CRUD、统一排期、动作预览编辑与批准/重试/核实）、事件日志（游标加载更多+自动刷新）。
- 验证：vue-tsc 类型检查通过，`npm run build` 通过（约 7s）；dev 服务器 5173 冒烟 200，/api 代理到 127.0.0.1:8000 的 /api/health 返回 200（本机后端在运行）。
- 已知点：Element Plus 主包 chunk >1MB（未做 manualChunks）；会议/通知平台后端未实现，前端明确展示 not_configured 不伪装成功。
