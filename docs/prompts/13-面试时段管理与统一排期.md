## 功能要求

1. 创建 slots、reservations 及候补记录；配置四个不重叠的实际时段，每个 45 分钟、接纳一人，保留时区。
2. 仅处理当前有效批准且有有效评估者；批次评估稳定后统一排序，总分优先，再按岗位指定维度，候选人 ID 最终稳定排序。
3. 在 MySQL 短事务内处理批次/时段锁和唯一约束；同一候选人不重复预约，同一时段不重复占用。
4. 超过容量、冲突等写明候补原因；后批准者只用剩余时段，不挤出已有预约；已占用时段不允许直接改删。
5. 本阶段不调用会议或通知服务。
