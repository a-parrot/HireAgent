## 功能要求

1. 规则包含稳定维度 ID、名称、标准、最高分、证据说明；硬条件支持简单 all/any 组合，不做脚本规则引擎。
2. 发布检查维度 ID 唯一、最高分为正整数且合计 100、0≤复核阈值<推荐阈值≤100、排序引用有效且不重复。
3. 发布时创建不可覆盖快照，事务内分配版本号；修改后发布新版本，历史结果仍绑定旧版本。
4. 停用岗位保留历史查询，禁止其创建新批次；受保护属性不能成为评分条件。

## 接口与交接

POST /api/jobs/{id}/publish、POST /api/jobs/{id}/disable；历史版本通过岗位详情查询。 编码前检查前序实际字段与响应格式，补充本任务契约并保持既有调用兼容。

## 验收条件

- 非法规则不能发布；不同维度数量的合法规则可发布。
- 发布 v2 不改变 v1；停用后历史仍可查询。
- 重复或并发发布不会产生相同岗位版本号。
